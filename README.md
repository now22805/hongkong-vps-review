## 几条宣传页不会主动告诉你的限制

下面这几条都写在官方文档里，但首页不会提，而它们直接影响业务能不能扛住。

**第一，600Gbps 防护不是默认送的。** 官网首页把 "up to 600 Gbps mitigation capacity" 放在很显眼的位置，官方文档写的却是：所有实例默认只有 best-effort 基础清洗，600Gbps 专业清洗是需要付费的附加项，价格没公开。更关键的是黑洞机制——当攻击大到影响同网段其他客户时，系统会对实例 IP 执行 null route，持续 30–60 分钟，自动解除，不能手动干预。这段时间里入站和出站流量全部丢弃，服务直接不可用。游戏服、实时业务、跨境后台要提前想好这个窗口期怎么办。

**第二，流量按出站单向计，买的流量包当月作废。** 官方计费说明写的是只统计出站流量，入站不计费，每月配额在计费周期开始时重置。流量不够可以单买：100GB $6、500GB $30、1TB $60、2TB $120、5TB $300、10TB $600、20TB $1,200，付款后立即加入当月配额，但只在当前周期有效，不结转。长期不够用，官方自己的建议是升级套餐。Forge 系列写明了超量 $0.06/GB，普通 VPS 超量之后是停机还是限速，文档没交代，别自己脑补。

**第三，到期没有宽限期。** 官方计费文档写得很硬：到期日当天服务立即暂停，没有 grace period；逾期 5 天服务终止，数据可能无法恢复；逾期 6 天发票自动取消。续费提醒在到期前 7 天发出，有信用卡在档还会自动扣款。当成生产环境用的话，提前充值余额或者绑卡自动续费，比事后找客服现实。

**第四，24 小时退款是真的，但有几条不适用。** 官方退款政策确认：服务开通 24 小时内可以申请全额退款，退回原支付方式，每人限一次，仅限首次购买，续费订单不适用。支付宝 1–3 个工作日到账，信用卡 5–10 个工作日，加密货币 1–3 个工作日。不适用的情况里有一条值得单独拎出来：**因 DDoS 攻击被黑洞的 IP 不予退款**。也就是说，机器因为被打进黑洞而不可用，这条路走不通。

**第五，Windows 和 IPv6 都别默认。** 商品页只在 Pulse 的 Pro/Ultra、Turin 的 Pro/Ultra、Peak X5 的 Pro 上标了 Windows-ready，低配档没有标注，这不代表装不了，但官方不承诺。资料里只写了 1 个 IPv4，没有 IPv6 的信息，有需求先问。

## 常见问题

**香港VPS测出来多少延迟算正常？**

**GoMami 有测试 IP 可以先测吗？**
没有公开的测试 IP，也没有 Looking Glass。你能做的只有下单后用 `ping`、`traceroute`、`wget` 实测，然后在 24 小时内决定要不要退。

**GoMami 适合建站吗？**
香港和日本节点适合面向东亚用户的站点，Pulse 这条线的官方定位就是个人项目、中小型网站、开发测试、API 和代理加速。需要留意黑洞那 30–60 分钟，攻击打到影响同网段时站点会整体不可用，而且这种情况不在退款范围内。
